# Dashboard design

Operate surface: a compact editorial report with a persistent section navigation and
wide graph/table pairs. System sans typography, tabular numerals, warm neutral background,
dark navy text and a restrained teal selection accent. Distinct orange dashed scope and
forecast traces supplement labels and tables; color alone never carries meaning.

Tokens: background #f5f6f3; surface #ffffff; text #182d35; secondary #425860;
accent #086a69; scope #96511c; line #c5cfce. Border-based separation without shadows.
Body 16px; headings 24/20px; report width 1180px; spacing 8/16/24/32px.
Native controls, visible focus rings, no entrance animation, no external type/assets.
Mobile stacks navigation/sections, and table overflow stays inside its labelled region.
