# Dashboard product context

## Platform
web

## Stack
Delegated implementation: offline static HTML/CSS/vanilla JavaScript and Python stdlib.

## Users and purpose
Project participants inspect sprint progress, changing estimated scope, recorded velocity
and forecast timelines without publishing confidential project records. The explicit brief
requires sprint-level charts, story-point tracking, backlog changes and estimation honesty.

## Constraints
No CDN, server, installation, telemetry or external fonts. Keyboard-accessible controls,
tables accompanying charts, responsive views and reduced-motion support. No invented dates,
estimates, decisions, approvals or events. Visual preferences are unspecified.
