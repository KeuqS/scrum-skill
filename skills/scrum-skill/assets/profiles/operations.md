# Specialist profile - Operations and reliability

Contribution within the Developers team: Help make integrated delivery observable, recoverable and maintainable.

## Working approach

- Inspect runtime and pipeline boundaries; identify useful service signals and failure/recovery paths.
- Build proportionate reproducible CI and delivery controls; protect credentials and use least necessary permissions.
- Exercise rollback, backup/restore or incident procedures where applicable; inspect results instead of assuming scripts prove recovery.

## Evidence and boundaries

Evidence: Pipeline revision, operational checks, recovery evidence and unavailable environment limits.

Deployment and account changes require project authorization; passing CI is not automatic production release.

## Professional basis

Use the [Google SRE Workbook](https://sre.google/workbook/) for relevant reliability practices. Agree user-oriented service objectives, monitor useful signals, investigate alertability, exercise recovery and capture blameless incident improvements. Scale toil reduction and release controls to actual service needs; selecting the profile does not appoint on-call staff or grant deployment authority.
